# ft_printf

## Description
Un projet qui demande de reproduire le comportement de la fonction printf en c.

## Fonctionnement
Lors de la compilation, un fichier de bibliothèque statique est généré pour utiliser cette fonction.
Pour tester la fonction, l'ajout d'un `main` est nécessaire.

### Utilisation
```bash
make
```
