# Libft

## Description
Le premier projet de l'école 42. Une bibliothèque de fonctions utiles en C.

## Fonctionnement
Lors de la compilation, un fichier de bibliothèque statique est généré pour utiliser ces fonctions.
Pour tester une fonction, l'ajout d'un `main` est nécessaire.

### Utilisation
```bash
make
make bonus
```
